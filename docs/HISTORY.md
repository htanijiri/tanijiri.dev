# tanijiri.dev ― 開発の記録

## 1. このアプリは何か
個人名刺の QR コードと NFC タグの飛び先にする、スマホ向けの静的なプロフィールサイト。
第一の役割は「名刺の裏側」で、名刺を受け取った相手が「この人は何を作っている人か」を数十秒で把握できることがゴール。

### 出発点となった要望（2026-09-29）
- 勉強会やハッカソンなど、オフラインで技術者と話す機会が増えたので、会社ではなく個人名義の名刺を作ることにした。
- その名刺に載せる QR コードと、スマホ背面やカードケースに仕込む NFC タグの飛び先として、このサイトが必要になった。
- 名刺はすでにデザイン済み（91×55mm・横、表裏2面）。サイトの氏名・肩書き・一行紹介・配色は名刺に揃える。
- 載せたいもの：名前、肩書き、一行紹介、各リンク（GitHub / Zenn / LAPRAS / メール）、そして本体となる「作っているものの一覧」（AI エージェント、業務効率化ツール、ローカル LLM 環境の構築・検証など）。Zenn の記事一覧への導線も候補。
- 載せないもの：勤務先名・客先名・案件の詳細、職務経歴書レベルの経歴。
- 進め方：ドメイン取得 → サイトを実装・公開 → 公開を確認してから名刺を入稿 → NFC タグに同じ URL を書き込む。

## 2. 主要な設計判断と、その理由

### 会社の名刺ではなく個人名刺にする
- 会社の看板を出さずに個人として渡したい（転職の可能性もある）。
- 会社の名刺は認証番号の変更や移転などで刷り直しが多い。個人名刺＋自分のサイトなら、変わる情報はサイト側で直せる。

### リンクまとめサービスではなく、自分のドメインに置く
- リンクまとめ系サービスは、サービス終了で URL ごと消えるリスクがある。紙に刷る以上、自分が所有するドメインであることを必須とした。
- ドメインは Cloudflare Registrar で `tanijiri.dev` を取得する（原価提供で更新時の値上げがない）。
- 趣味用に持っている別ドメインとは用途を分ける。将来は `blog.` `app.` `api.` `demo.` などのサブドメインに広げる余地を残す。

### 肩書きは「エンジニア / 個人開発」、一行紹介は「自分が使うものを、自分でつくるのが好きです。」
- 当初は「業務システムエンジニア × 生成AI」としていたが、「×」だと「業務システムを生成 AI で開発している」と読める。実際は業務システムが仕事、生成 AI が個人開発で、別物。
- この名刺は勉強会用で転職活動用ではないので、業務色を前面に出す必要がない。
- 一行紹介の芯は「プログラミングそのものより、自分好みのアプリやシステムを手に入れて使うことが好き」という自己理解。生成 AI で作る負荷が下がり、工数の制約で諦めていたことが実現できるようになった。
- サイトの文言もこのトーン（実装者としての自慢ではなく、作って使う人としての素朴さ）に揃える。

### 静的サイト・1ページ構成・モバイルファースト
- 中身はプロフィールとリンクと作品一覧なので、静的サイトで十分。1ページから始めて、必要になったら足す。
- QR・NFC 経由でスマホから開かれるので、モバイルファーストで作る。
- `.dev` ドメインは常時 HTTPS が必須だが、候補のホスティング（Cloudflare Pages / GitHub Pages）はどちらも標準で対応している。

### 見た目は名刺に揃える
- 白地＋チャコール（本文）＋グレー（サブ）＋深いティール（アクセント）の4色だけ。色数を増やさず、装飾は最小限で余白で見せる。
