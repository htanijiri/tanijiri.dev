# 003 X へのリンク

- 状態：実装中
- 依存：001

## 背景・課題
勉強会で会った人とのその後のつながりは、X のフォローが多い。今のサイトの連絡手段はメールだけで、メールを書くのは腰が重い。GitHub と Zenn には、DM に当たる気軽な連絡手段がない。
X のアカウント（技術用）はほとんど投稿していないので、「読んでもらう場所」ではなく「フォローの窓口」として載せる。DM は、フォローしあってから使う（2026-10-03 変更。下の「X 側」を参照）。
個人の名刺に X がないのは不自然に見える、というユーザーの判断で、名刺の裏面にも載せる。

## ゴール
- トップページのリンク欄に、X（技術用のアカウント）へのリンクを1行足す。並びは GitHub / Zenn / X / Mail。
- 名刺の裏面に X の行を足す。並びは Mail / GitHub / Zenn / X / Web。
- サイトや名刺から来た人がフォローし、こちらがフォローを返したら DM でやりとりできる。フォローしていない相手からの DM は受け取らない。

## やらないこと
- Facebook へのリンク。
- 趣味用のアカウントへのリンク。
- 投稿の埋め込み、タイムラインの表示。
- X のロゴ画像（ほかのリンクと同じく文字だけ）。
- `twitter:card` などの X 向けメタ情報（OGP 画像と合わせてフェーズ2）。
- X のユーザー名の変更（GitHub・Zenn のユーザー名とはそろえない）。名刺に刷るので、刷ったあとは変えない前提にする。

## 設計方針
**サイト**
- `public/index.html` のリンク欄（`<dl>`）に、Zenn と Mail の間へ1項目足す。`<dt>` は `X`、表示は `x.com/hirota2`（ほかの行と同じ「ドメイン/ユーザー名」の形）。
- リンク欄の HTML コメント「名刺の裏面と同じ連絡先」はそのまま（名刺にも X が載るので、内容は同じ）。
- URL は `x.com` で書く（`twitter.com` は `x.com` へ転送される。2026-10-02 に `curl -L` で確認）。
- `scripts/check.sh`：リンクの確認に X の URL を足し、AC2 の並び順の確認を足す。X は `curl` に対して、存在するユーザー名に `200`、存在しないユーザー名に `404` を返す（2026-10-02 確認）ので、ほかのリンクと同じ方法で確認できる。
- CSS は変えない見込み（行が1つ増えるだけ）。AC4 で崩れたら、先にこの仕様書を直す。
- README.md のリンクの記載（GitHub / Zenn / メール）に X を足す。

**名刺（`brief/` の名刺データ。Git 管理外）**
- 裏面の Zenn の行と Web の行の間に、X の行を足す。ラベルは `X`、値は `x.com/hirota2`。書式（フォント・大きさ・色）は Zenn の行と同じ。
- 行の位置：今は4行が 7.8mm 間隔（上端が 17.5 / 25.3 / 33.1 / 40.9mm）。同じ間隔で5行目を足すと下端が 52.7mm になり、紙の下端（55mm）に近すぎる。1行目と最終行の位置は変えず、間隔を 5.85mm に詰める（17.5 / 23.35 / 29.2 / 35.05 / 40.9mm）。右側の QR と説明文の位置は変えない。
- 今のファイルは上書きせず、別名で保存する（表面のアイコン追加のときと同じ）。
- 試作（2026-10-02）：上の位置で作って画像にし、重なりがないことを確認した。

**X 側（ユーザーの作業）**
- DM：フォローしていない相手からのメッセージリクエストは受け取らない（「メッセージリクエストを許可するアカウント」を「なし」にする。2026-10-03 決定）。X では、自分がフォローしている相手からの DM は届く。流れは「相手がフォローする → フォローの通知が来る → こちらがフォローを返す → DM でやりとりできる」。フォローの通知は届くので、見に行く必要がない。
- 「全員」にしなかった理由（2026-10-03 に試してわかったこと）：フォローしていない相手からの DM は、アプリの「チャット」画面の通常の一覧に出ず、メッセージリクエストのさらに「その他」に振り分けられて、通知も来なかった。名刺を渡してすぐ連絡が来るものでもなく、そこを頻繁に見に行くこともできない。
- 「認証済みアカウント」（「全員」にする前の設定）も選ばない：認証済みのアカウントからの DM もリクエストに入り、ふだん見に行かないので見落とす。勉強会で会う人の多くは認証済みではなく、この設定で DM を送れるようになる相手はほとんどいない。「フォローしあってから」の方針と一致する「なし」のほうがわかりやすい。
- プロフィール（2026-10-02 に変更済み）：自己紹介は名刺の肩書き・一行紹介と同じ文言に、作っているものの一文を足したもの。ウェブサイトの欄に `tanijiri.dev`。アイコンはサイトと同じハリネズミのイラスト。場所の記載は今のまま。

## 検討した案と不採用の理由
| 案 | 採用 | 理由 |
|---|---|---|
| サイトのリンク欄に X を足す | 採用 | フォローの窓口になる。フォローしあえば DM も使える。 |
| DM を全員から受け取る | 不採用 | 届いてもリクエストの「その他」に入り、通知もなく気づけない。「送れるのに返事が来ない」になる（2026-10-03 に試して変更、ユーザー判断）。 |
| 名刺の裏面にも X を刷る | 採用 | 個人の名刺に X がないのは不自然に見える（ユーザー判断）。Claude は「刷るとあとで外せないので、サイトだけ」を案にしていた。 |
| 名刺の5行目を同じ間隔（7.8mm）で足す | 不採用 | 下端が紙の端から 2.3mm になり、近すぎる。 |
| X のユーザー名を GitHub・Zenn と同じにする | 不採用 | 今のユーザー名のまま使う（ユーザー判断）。 |
| Facebook も載せる | 不採用 | 私的なつながりと混ざる。勉強会で会った人との接点としては X で足りる。 |
| 表記を `Twitter` にする | 不採用 | 現在のサービス名と URL（`x.com`）に合わせる。 |
