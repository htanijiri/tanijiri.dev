# 001 プロフィールページ

- 状態：実装中
- 依存：000

## 背景・課題
名刺の QR・NFC から来た人が、スマホで開いて数十秒で「誰で、どこを見れば作ったものや記事がわかるか」をつかめるようにしたい。
名刺に刷った文言・配色とサイトがずれていると、同じ人の名刺とサイトに見えない。また肩書きなどは今後変わりうるので、サイト側だけで楽に書き換えられる必要がある。

## ゴール
- トップページ（`https://tanijiri.dev/`）の最初の画面に、名刺表面と同じ内容が出る。
  - 氏名（漢字表記とローマ字表記。名刺表面と同じ）
  - 肩書き：`エンジニア / 個人開発`
  - 一行紹介：`自分が使うものを、自分でつくるのが好きです。`
- 外部へのリンク：GitHub / Zenn / メール。
- アイコン：ハリネズミのイラスト（GitHub・Zenn と同じ画像）。favicon も同じイラストを縮小して使う。
- 見た目は名刺に揃える（配色4色、装飾は最小限、余白で見せる）。
- 文言とリンクの URL は1か所にまとまっていて、書き換えるときに触るファイルが1つで済む。

## やらないこと
- 作っているものの一覧（spec 002 で扱う）。
- Zenn の記事一覧の自動取得（フェーズ2で検討）。
- 勤務先名・客先名・案件の詳細、職務経歴書レベルの経歴の掲載。
- ダークモード（白背景だけ。名刺にない色を足さない）。
- 英語版ページ・英語の一行紹介（日本語のみ。氏名のローマ字表記はある）。
- アイコン以外の画像の掲載（顔写真など）。
- Web フォント。
- OGP 画像（フェーズ2）。
- お問い合わせフォーム（メールリンクで足りる）。
- 転職サイト（LAPRAS など）へのリンク（2026-09-29 決定）。

## 設計方針
- 1ページ構成。上から「氏名・肩書き・一行紹介」「リンク」「作っているもの（spec 002）」の順。
- 素の HTML＋CSS（ビルドなし）。`public/index.html` と CSS ファイル1つを基本にする。文言・リンクの URL は `public/index.html` にまとめる。
- 色は CSS のカスタムプロパティ（変数）4つで定義し、それ以外の色を書かない。
- フォントは名刺に合わせて日本語は游ゴシック系、英字は Arial / Helvetica 系を指定し、Web フォントは使わない。游ゴシックは Windows・Mac にしかなく、iPhone ではヒラギノ、Android では Noto Sans CJK になる。
- 外部リンクは同じタブで開く（`target="_blank"` を付けない）。
- テキストの OGP（`og:title`、`og:description`、`og:url`、`og:type`）を入れる。
- アイコン：元画像（512×512 の PNG、約 400KB。`brief/` に置き、リポジトリには入れない）から、256×256 の WebP（約 11KB）を作って置く。表示は 128px 以下にする（高精細な画面で2倍の解像度になる）。`alt` には氏名を入れる。`width`・`height` を指定して、読み込み時にレイアウトがずれないようにする。
- イラストの色（ベージュ・茶色）は画像の中だけで、CSS の配色には使わない（AC4 は CSS の色だけを対象にする）。
- favicon：同じイラストから 32×32 の PNG を作って置き、iPhone のホーム画面用に 180×180 の PNG（`apple-touch-icon`）も置く。
- 予備のマーク（favicon がつぶれて見える場合の代わり。2026-09-30 作成の候補 C）：
  ```svg
  <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
    <rect width="64" height="64" rx="14" fill="#1F7A6C"/>
    <g fill="#FFFFFF">
      <rect x="9" y="16" width="7" height="32"/><rect x="24" y="16" width="7" height="32"/>
      <rect x="9" y="29" width="22" height="6"/>
      <rect x="34" y="16" width="22" height="6"/><rect x="41.5" y="16" width="7" height="32"/>
    </g>
  </svg>
  ```

## 検討した案と不採用の理由
| 案 | 採用 | 理由 |
|---|---|---|
| 名刺と同じ4色だけで組む | 採用 | 名刺と同じ人のサイトに見えることを優先。計画時に「色数を増やさない」と決めている。 |
| アイコンにハリネズミのイラストを使う | 採用 | 覚えてもらいやすく、GitHub・Zenn と同じ画像で、会った人とアカウントがつながる。 |
| 頭文字のマーク（HT）を favicon にする | 予備 | 16px の画面ではつぶれるイラストより読みやすいが、高精細な画面ではイラストでも許容範囲だったので、イラストにそろえた。 |
| Web フォントで游ゴシック相当を配信 | 不採用 | 端末差はなくなるが、日本語 Web フォントは重く、AC9 の転送量を超えやすい。 |
| 経歴・スキル一覧をページに載せる | 不採用 | 名刺は勉強会用で転職活動用ではない。 |
