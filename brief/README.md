# brief/

チャット（Claude.ai / ChatGPT）で相談してまとめた計画書を置く場所。

- 計画書は `BRIEF.md` という名前で置く。Claude Code はここから作業を始める（[CLAUDE.md](../CLAUDE.md) の「出発点は計画書」）。
- 相談で使った資料（ワイヤーフレーム、スクリーンショット、チャットのログなど）も、必要ならここに置いてよい。
- BRIEF は相談した時点の記録として残し、あとから書き換えない。その後に決まったことは `docs/specs/` と `TASKS.md` に書く。
- **このフォルダは、この README 以外 gitignore されている**（個人情報や社内情報が混ざる可能性があるため）。公開しても問題ない内容であれば、`.gitignore` の `brief/*` の行を消す。
