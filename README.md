# tanijiri.dev

個人名刺の QR コードと NFC タグの飛び先にするプロフィールサイト。
名刺を受け取った技術者が、スマホで開いて「この人は何を作っている人か」を数十秒でつかめることを目指す。

## 設計の前提（なぜこの作りか）
- **名刺の裏側として使う。** 勉強会やハッカソンで渡す個人名刺の QR・NFC の飛び先。主にスマホで開かれるので、モバイルファーストで作る。
- **自分が所有するドメインに置く。** 紙に刷る URL なので、リンクまとめ系サービスのように、サービス終了で URL ごと消えるリスクを避ける。
- **中身を後から書き換えられる。** 肩書きや作っているものが変わっても、名刺を刷り直さずにサイト側だけ更新できる。
- **静的サイトで、1ページから始める。** 必要になったらページやサブドメインを足す。
- **載せないもの**：勤務先名・客先名・案件の詳細、職務経歴書レベルの経歴。
- 見た目は名刺に揃える（白地＋チャコール＋アクセント1色、装飾は最小限）。

詳しい経緯は [docs/HISTORY.md](docs/HISTORY.md)。

## 主な機能
- プロフィール：名刺と同じ氏名・肩書き・一行紹介（→ [spec 001](docs/specs/001-プロフィールページ.md)）
- リンク：GitHub / Zenn / X / メール（→ spec 001、X は [spec 003](docs/specs/003-Xへのリンク.md)）
- 作っているものの一覧：GitHub で公開している個人開発物の紹介（→ [spec 002](docs/specs/002-作っているもの一覧.md)）

## 構成
素の HTML＋CSS の静的サイト（ビルドなし）を Cloudflare Pages で配信する。
```
public/                  # 配信するファイル（Pages の出力ディレクトリ）
  index.html             # 文言・リンク・作っているもの（中身はすべてここ）
  style.css              # 見た目（名刺の4色だけ）
  404.html               # 存在しないパス用
  icon.webp, favicon-32.png, apple-touch-icon.png
scripts/
  check.sh               # 受け入れ条件のうちコマンドで確認できるものをまとめて確認
  make-icons.sh          # 元画像からアイコン・favicon を作る
docs/                    # 仕様書・技術ノート・デプロイ手順
TASKS.md                 # タスクと決定事項
```

## セットアップ
ビルドも依存パッケージもない。設定ファイルや秘密情報もない。
```bash
python3 -m http.server -d public 8000     # http://localhost:8000 で表示
scripts/check.sh http://localhost:8000    # 確認
```

## デプロイ
Cloudflare Pages（Git 連携）。`main` に push すると本番に反映される。手順とロールバックは [docs/DEPLOY.md](docs/DEPLOY.md)。
